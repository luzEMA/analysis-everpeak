# Movilidad Urbana y Economía
Analizar conjuntos de datos relacionados con la movilidad de transporte y su impacto o relación con indicadores económicos.

## Técnicas aplicadas
- Limpieza de datos y manejo de valores faltantes con Pandas.
- Análisis exploratorio de datos (EDA): estadísticas descriptivas, agrupaciones y visualizaciones.
